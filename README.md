# Spots we love in NYC

Devika and Rahul’s food and drinks guide, published at https://devika-and-rahul.github.io/.

Both sections share one continuous, responsive page. The floating Food/Drinks menu jumps to either section and stays visible as you scroll. Venue names open Google Maps searches.

## Edit

- `index.html`: venues, notes and page content.
- `styles.css`: layout, colors and phone styles.
- `app.js`: highlights the section currently on screen.
- `assets/`: optimized textures, block print and lotus artwork.

Open `index.html` locally to preview. There is no build step, package installation or backend. GitHub Pages publishes the root of `main`; `.nojekyll` keeps these files static.
